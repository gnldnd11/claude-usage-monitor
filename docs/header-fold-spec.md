# 머리글·접기·세션 없는 계정 규격

> 2026-11-19. 사용자가 올린 하자 넷(A~D)과 조정자가 더한 하자 하나(E)를 한 장으로 묶은 것이다.
> **E 가 1번이다.** A~D 는 보기의 문제이고 E 는 화면이 거짓을 그리는 문제다.
>
> 이 문서의 모든 수치는 `tools/shoot-panels.mjs` 로 **실제로 렌더해서 잰 값**이다.
> 계산한 값에는 「계산」이라고 적었다. 계산값은 구현 뒤에 반드시 다시 재야 한다.
> 기준 폭은 사이드바 351(집 기본값), 라이트 테마다.
>
> 충돌하면 `docs/game-panels.md` 가 이긴다. 그 문서 2절 210행이 **Usage 탭도 그 규격에 걸린다**고
> 못 박아 두었으므로, 이 문서는 그 아래에 있다.

## 0. 열고 3초

**지금 화면(세션 창 있는 계정).** 패널 맨 위에 「Claude Usage」가 제일 큰 글자로 있는데,

게가 둘이고 서로 다른 그림이다. 머리의 주황 게와 링 옆의 갈색 게.

**세션 창이 없는 계정(사용자 계정).** 화면에서 제일 큰 것이 **빈 회색 도넛에 작대기 하나**다.
눈이 거기로 가고, 거기에는 아무것도 없다. 숫자가 있는 것들은 전부 왼쪽에 작게 있다.
아래 타일에도 작대기가 하나 더 있다. **고장난 화면으로 읽힌다.**

**접었을 때.** 막대 셋 아래에 설명 없는 빈 띠가 남고, 머리의 게가 **세 번째 게**로 바뀌고,

## 1. 하자 E (우선순위 1). 세션 창이 없는 계정에서 링과 그 주변이 죽는다

### 1-0. 사실 확인

2026-10-30 에 Max 20x 가 Ultra 로 바뀌었고 **인증된 Ultra 계정에는 5시간 세션 한도가 없다.**
주간 한도(전 모델 공통 + Fable 별도)는 남는다. Pro 와 Max 는 5시간 창이 그대로 있다.
`globalState` 의 `usageCacheV1` 에 담긴 이 계정의 마지막 성공 응답은 `five_hour: null` 이다.

호스트는 이미 옳다. `extension.js:1147,1177` 가 한도가 없으면 그 필드만 null 로 두고,
`extension.js:1266` 이 그대로 푸시한다. **깨지는 곳은 웹뷰다.**

### 1-1. 판별식. 「모르겠다」와 「없다」를 가르는 한 줄

지금은 둘 다 `—` 다. `webview.js:1309,1311` 가 `d.usageLoading ? '…' : '—'` 다.
기다리면 오는 것과 기다려도 안 오는 것이 같은 글리프다.

**호스트를 고치지 않고 가를 수 있다.** `extension.js:1146~1150` 과 `1176~1180` 이 응답마다
`usageCache` 를 통째로 다시 만들고, 없는 한도만 null 로 둔다. `usageLoaded` 는 성공 파싱이나
복원(`extension.js:1751~1755`) 뒤에만 true 다. 따라서,

```js
// webview.js. 셋을 가르는 유일한 식. 다른 곳에서 fh == null 을 직접 보지 않는다
var loading   = d.usageLoading === true;                       // 아직 모른다        -> '…'
var noSession = !loading && d.sd != null && d.fh == null;      // 이 계정에 없다     -> 자리를 없앤다
var failed    = !loading && d.sd == null;                      // 왔는데 둘 다 없다  -> '—' + warnbar
```

**`noSession` 이면 `<body>` 에 `no-session` 클래스를 건다.** 아래 모든 상태 2 규칙이 이 한 클래스에
매달린다. 클래스 하나로 묶는 이유는, 분기가 여섯 군데로 흩어지면 다음 사람이 그중 하나를 빠뜨리기
때문이다. 지금 빠뜨려진 것이 정확히 그 모양이다.

### 1-3. `Active time` 타일. 조정자의 진단을 반려한다

> 조정자의 권고: 「`Active time` 은 트랜스크립트에서 나오는 값이니 `fh` 에서 떼어낸다」

**틀렸다. 떼어낼 곳이 없다.** `webview.js:27` 의 `activeTime(r)` 은 이렇게 생겼다.

```js
function activeTime(r) {
  if (!r) return '–';
  var el2 = 5 * 3600 - (r - Date.now() / 1000);   // 5시간 창 안에서 얼마나 왔나
  ...
}
```

이것은 트랜스크립트 값이 아니라 **5시간 창의 경과 시간**이다. 창이 없으면 이 수는 정의되지 않는다.
호스트가 푸시하는 것 중 트랜스크립트에서 오는 시간 값은 `d.last.t`(오늘 마지막 메시지, `extension.js:439,458,1272`)
하나뿐이고, `today`(`extension.js:1271`)는 토큰 수만 담는다. **활동 시간이라는 값은 이 제품에 아직 없다.**

| | 안 | 어떻게 | 판정 |
|---|---|---|---|
| 1 | **`Active today`** | 호스트가 `firstT`(오늘 첫 메시지 시각)를 하나 더 푸시한다. `extension.js:438~476` 의 이미 도는 루프에 `if (!first \|\| msg.t < first.t) first = msg;` 두 줄. 타일은 `last.t - firstT` 를 지금 포맷(`3h 12m`)으로 그리고 라벨을 `Active today` 로 바꾼다 | **권고** |
| 2 | `Last active` | 호스트 무변경. `agoText(d.last.t)` | 거의 항상 `now` 라 정보가 없다 |
| 3 | 타일을 뺀다 | 타일 셋이 둘이 된다 | **반려.** `.stats` 의 1px 구분선 격자가 바뀌어 상태 1 과 다른 화면이 된다 |

**안 1 은 상태 1 에도 똑같이 적용한다.** 상태 1 의 `Active time` 은 「창 안에서 얼마나 왔나」라서
창이 한 번 돌면 0 으로 떨어진다. 그것이 지금 라벨이 말하는 「활동 시간」인지는 따로 물을 일이고,
이 블록에서는 **상태 1 의 값과 라벨을 바꾸지 않는다.** 상태 2 에서만 `Active today` 를 쓴다.
한 화면에 라벨이 둘인 것이 걸리면 그때 사용자에게 묻는다.

### 1-4. 마스코트. 여기가 이 블록에서 제일 어렵다

#### 지금 무엇이 깨졌나

```js
// webview.js:1275
var _state = mascotState((d.fh && d.fh.used_percentage) || 0, (d.sd && d.sd.used_percentage) || 0);
```

`fh` 가 null 이면 첫 인자가 **영구 0** 이다. `mascotState`(`webview.js:1220~1234`)에서 단계를 올리는
것은 첫 인자뿐이고, 둘째 인자는 `weekly >= 100` 일 때 **곧장 최상단으로** 올린다.
따라서 이 계정에서 **네 상태 중 둘(idle, stunned)만 도달 가능하고 사이의 둘은 영원히 안 나온다.**
`_mascotDrawn`(`webview.js:1281`)도 `d.fh` 에 매달려 있어 영원히 false 다. 전환 비트도 안 돈다.

#### 판정: 주간 raw % 를 세션 축에 그대로 꽂으면 안 된다

조정자의 걱정이 맞다. 주간은 7일에 걸쳐 차므로 주간 50% 는 세션 50% 와 다른 뜻이다.
그대로 옮기면 한 주의 거의 전부를 idle 로 보낸다.

**페이스로 바꾼다.** 사용자가 알고 싶은 것은 「지금 쓰는 속도로 가면 리셋 전에 바닥나는가」이고,
그것이 페이스다.

```js
// 상태 2 에서만. 상태 1 은 이 코드를 타지 않는다
var W = 7 * 86400;
var e = Math.min(1, Math.max(0, 1 - (d.sd.resets_at - Date.now() / 1000) / W)); // 주간 창의 경과 비율
var expected = Math.max(5, e * 100);                      // 정각에 딱 맞춰 소진하는 페이스
var strain = Math.min(100, Math.round(d.sd.used_percentage / expected * 50));
var _state = mascotState(strain, d.sd.used_percentage);
```

| 왜 이 식인가 | |
|---|---|
| `* 50` | pace 1.0 이 50(working 선), 1.4 가 70(despair), 1.8 이 90(stunned)이 된다. **`MASCOT_STEPS` 표와 데드밴드를 한 글자도 안 고친다** |
| `max(5, ...)` | 주 시작 8.4시간 동안 `expected` 가 0 에 가까워 페이스가 폭발한다. 하한이 그걸 막는다 |
| `mascotState` 둘째 인자 | 주간 100% 는 지금도 stunned 다. 그대로 둔다 |

**Pro·Max 경로가 바뀌지 않는 것이 약속이 아니라 구조다.** `mascotState` 와 `MASCOT_STEPS` 를 안 건드리고
입력만 다르게 넣으므로, 상태 1 에서는 지금 돌던 코드가 그대로 돈다.

`_mascotDrawn` 도 같이 고친다. `webview.js:1281` 의 `if (d.fh && ...)` 를
`if (d.fh ? d.fh.used_percentage != null : noSession)` 로 넓힌다. 안 그러면 상태 2 에서 비트가 영원히 안 돈다.

#### 이 식으로 사용자 계정이 지금 어떻게 되나 (실측 입력으로 계산)

사용자 계정의 마지막 성공 응답(`seven_day`: used 18%, resets_at 1795438800)과 2026-11-19 03:19Z 기준.

| | |
|---|---|
| 주간 경과 비율 `e` | 0.371 (리셋까지 4.40일) |
| `expected` | 37.1 |
| pace | 0.485 |
| `strain` | 24 |
| 마스코트 | **idle** |

**오늘 이 계정이 idle 인 것은 맞다.** 쓸 수 있는 양의 절반 페이스로 쓰고 있다.
**고치는 것은 「지금 idle」이 아니라 「영원히 idle」이다.** 같은 계정이 오늘 시점에
working 이 되는 선은 주간 37.1%, despair 48.2%, stunned 59.4% 이고, 전부 도달 가능한 수다.

## 3. 하자 C. Agents 탭으로 가면 게가 30px 뛴다

## 4. 하자 B. 접기가 무의미하다

### 4-1. 실측. 세 셰브론의 반환량은 거의 같다

| 버튼 | 무엇을 접나 | 펼침 `.card` | 접힘 `.card` | 차이 |
|---|---|---|---|---|
| `#toggle` | Usage 패널 전체 | 440.59 | **318** | -122.59 (-27.8%) |
| `#wsFold` | Agents 의 방 | 596.63 | **442.75** | -153.88 (-25.8%) |
| `#crewFold` | Agents 의 Crew | 596.63 | **442.66** | -153.97 (-25.8%) |

**조정자가 적은 「`#crewFold` 는 10px」은 측정 중 튄 값이다.** 같은 명령을 네 번 돌려 네 번 다
442.66 이 나왔다. 측정 프로토콜은 7-3 에 적었다.

따라서 **「세 개가 서로 다른 셋을 접는데 같은 셰브론을 쓴다」는 하자가 아니다.** 셋 다 네 자리 중

무엇을 접는지는 자리가 말한다. 이건 취향이고, 바꿀 이유를 못 찾았다.

### 4-2. 그러면 왜 무의미하게 느껴지나. 이유 둘

**(1) 접은 패널의 절반이 틀이다.** 접힘 318 의 내역을 재면,

`styles.js:165` 가 `.compact .ringbox{max-width:0}` 만 걸어서 **폭만 0 이고 높이 180 을 그대로 들고 있다.**
실측: 접힘에서 `.ringbox` 0 x 180, `.meters` 153, `.body` 180. 차액 27 이 그 유령이다.
스크린샷에서 막대 셋 아래의 설명 없는 빈 띠가 정확히 그것이다.

**(2) 접어도 새로 보이는 것이 없다.** Usage 패널은 펼쳐도 440.59 라 보통 사이드바 높이에 이미 다

Agents 탭은 596.63 이라 짧은 사이드바에서 넘치고, 그래서 그쪽 접기는 일을 한다.
**같은 27%를 돌려줘도 체감이 다른 이유가 이것이다.**

## 5. 하자 D. 새 그림이 들어와도 안 깨지는 상자

사용자가 그림을 직접 다시 만든다. **APNG·`crab.png`·방 배경을 다시 그리라고 이 문서는 말하지 않는다.**
여기 적는 것은 **새 그림이 들어올 때 상자가 안 흔들리는 조건**뿐이다.

### 5-1. 큰 마스코트는 이미 돼 있다. 건드리지 않는다

`styles.js:45~62` 가 `.mascot-wrap` 을 74px 고정 + 아래 정렬 + `object-fit:contain` 으로 묶어 두었고
`test/panel-css.test.js` 가 네 PNG 의 헤더에서 수치를 다시 계산한다. **그대로 둔다.**

### 5-2. 머리의 44px 게에는 상자가 없다

```
.mascot{position:relative;flex:none;}                              /* styles.js:33 */
.mascot img{width:44px;height:auto;...}                            /* styles.js:34 */
```

`crab.png` 는 261x195, 비율 1.3385 다. 폭 44 에 높이 `44 / 1.3385 = 32.86` 이 **그림에서 나온다.**

지금은 `.ttl`(38.59)이 머리 높이를 잡고 있어서 안 흔들린다.
**하자 A 안 1 로 `.t1` 이 빠지면 머리 높이를 게가 잡는다.** 그때부터 비율이 곧 머리 높이다.

경계값: 머리가 커지기 시작하는 비율은 `44 / 38.59 = 1.1402`(지금), 안 1 뒤에는 `44 / 34 = 1.294` 다.
**`crab.png` 의 1.3385 는 그 선 바로 위에 서 있다.** 조금만 각지게 그려도 넘는다.

정사각 그림으로 시뮬레이션한 실측:

| | 지금 그림 | 정사각 그림 |
|---|---|---|
| `.mascot` | 44 x 32.86 | 44 x **44** |
| `.head` | 38.59 | **44** |
| `.card` | 440.59 | **446** |

**그림 하나를 바꿨는데 패널 전체가 5.41px 길어진다.** 그리고 `.bubble`(`styles.js:35`)이
`.mascot` 기준 `top:-10;right:-13` 이라 말풍선도 같이 움직인다.

### 5-3. 규격

```css
.mascot{position:relative;flex:none;height:34px;display:flex;align-items:flex-end;}
.mascot img{width:44px;height:100%;object-fit:contain;object-position:bottom;image-rendering:pixelated;display:block;}
```

|---|---|

### 7-5. 신선도 줄 (1.32.0, 사용자 지시)

`Usage summary` 는 지웠다. 이미 들어와 있는 탭의 이름을 다시 말하는 제목이라 판단이 없다.
`Updated` 는 **지우지 않고 평소에 숨겼다.** 엔드포인트가 조용해졌다는 신호가 이 칸 하나뿐이고,
링이 이제 주간을 그리므로(상태 2) 세 시간 전 % 를 지금 값처럼 보여 주면 거짓말이 된다.

| 상태 | 화면 | 재는 법 |
|---|---|---|
| 처음 불러오는 중 | `Checking usage` + 맥박 점 | `usageLoading: true` |
| 신선 | **아무것도 없음**(`#uhead` 0 x 0) | 기본 |
| 낡음 | `Usage 18m ago`, 점 없음(`#uhead` 273 x 12) | `--stale` |

**문턱 5분은 감이 아니라 호스트의 주기에서 끌어냈다.** `extension.js` 의 usage 루프는 로그인 시 60s,
공용 토큰 120s 로 돌고 거절은 30s 뒤 재시도하며, tap 값이 110s 미만일 때만 한 번 쉰다(tap 자체가
읽기다). 즉 **배관이 돌기만 하면 가장 새 답이 최악 2분**이다. 그리고 **300000 은 이 확장이 이미 쓰는
「너무 오래됐다」의 값**이다: 창 포커스 복귀와 패널 가시화, 두 기회성 갱신의 쓰로틀이 그 값이고 그보다
오래됐으면 가서 받아온다. 5분은 건강한 최악 간격의 2.5배이면서 호스트 자신이 침묵을 기대하지 않는 선이다.

**맥박 점은 「불러오는 중」에만 뜬다.** 그 점의 뜻이 「살아 있다」인데, 낡았다고 말하는 줄에 붙으면
반대를 말한다. 그리고 **접기는 이 줄을 숨기지 않는다**(`body.tab-usage.compact .ihead` 규칙 삭제).
접은 패널도 같은 숫자를 그리고 있으므로 접는 것이 경고를 없애는 방법이 되면 안 된다.

### 7-2. 도구에 필요한 것 둘. 구현자가 한다

**(1) `--no-session`.** `tools/shoot-panels.mjs:274` 의 `usageData()` 가 `fh` 를 항상 채운다.
플래그가 서면 `fh: null` 을 내게 한다. 없으면 하자 E 의 절반을 아무도 못 잰다.
(이 문서를 쓰면서는 스크래치패드에 도구 사본을 떠서 환경변수로 같은 일을 했다. 저장소 파일은 안 건드렸다.)

**(2) probe 타이머.** `tools/shoot-panels.mjs:596` 의 `setTimeout(..., 400)` 을 **700** 으로.
클릭이 180ms 에 돌고(`:580` 의 60 + 120) 전환이 450ms 라 630ms 가 지나야 자리가 선다.
지금은 460ms 에 잰다. 대개는 가상 시간이 밀어 줘서 제대로 나오지만 **다섯 번에 한 번쯤 튄다.**
조정자가 본 `.card` 427, 내가 한 번 본 `#crewFold` 586.63 이 둘 다 그 튄 값이다.

**둘 다 넣었다(1.32.0).** `usageData` 가 `session: false` 를 받고, `--no-session` 이 그것을 세운다.
타이머는 700 이다.

**타이머만으로는 안 됐다. 측정 전에 애니메이션을 끄는 것이 진짜 고침이다.** 700 으로 올린 뒤에도
같은 접힘 명령 네 번 중 **한 번이 튀었다**(`.card` 265 가 아니라 406, 링 칸은 전환 0% 인 88x180 그대로).
가상 시계에서는 전환이 시계와 함께 가기도 하고 **프레임이 안 그려져 전혀 안 가기도 한다.** 더 기다리는
것으로는 못 고친다. 그래서 `probe()` 가 **제품 자신의 `notrans` 클래스를 먼저 박는다**
(`styles.js`, 첫 페인트에 쓰는 그것). `transition:none` 이면 모든 속성이 목표값으로 즉시 서고,
그 값이 사용자가 결국 보는 값이다. 적용 뒤 **다섯 번 연속 265** 로 같다.
`--stale` 도 같은 이유로 더했다: 신선도 줄은 그것 없이는 아무도 못 잰다.

그리고 **(3) 을 하나 더 넣었다: 모르는 플래그면 돌지 않고 멈춘다.**
`--help` 가 플래그가 아니어서 기본 작업이 돌고 `media/` 6장을 덮어쓴 그 사고가, 「기본 작업이
파괴적인데 오타가 거기로 떨어진다」는 구조였다. 이제 `--help` 는 플래그 목록을 찍고,
모르는 플래그는 exit 2 다. 값 없는 플래그는 `BOOLS` 에 적어야 다음 인자를 안 삼킨다.
측정 산출물이 나가는 `tools/.measure/` 와 `tools/.shoot/` 는 `.gitignore` 에 넣었다.
지어낸 수치가 든 그림이 저장소에 들어오는 길을 하나 줄인다.

### 7-3. 측정 프로토콜

**접힘을 재는 값은 같은 명령을 두 번 돌려 같은 값이 나올 때만 적는다.**
두 번이 다르면 큰 쪽이 뛰는 중이다. 7-2 의 (2)를 먼저 하면 이 규칙이 필요 없어진다.

**(2)로도 안 없어졌고, `notrans` 를 박은 뒤에 없어졌다.** 700ms 로 올린 상태에서 네 번 중 한 번이
튄 실측이 7-2 에 있다. 지금은 측정 전에 전환을 끄므로 값이 결정적이다. **그래도 이 규칙은 남겨 둔다:
두 번 돌리는 비용이 20초고, 틀린 수치 하나가 규격에 박히는 비용은 그보다 크다.**

### 7-4. 눈으로 보는 것

계측이 통과해도 화면은 따로 본다. 이 하네스는 PNG 를 낼 수 있다
(`--probe` 를 빼고 `--out <경로>` 를 주면 그 폴더로 나간다. `--out` 없이 `--only` 없이 돌리면
`media/` 를 덮어쓰므로 그러지 말 것).

볼 것은 셋이다. 세션 있는 계정, 세션 없는 계정, 접은 상태. 라이트와 다크 둘 다.
**세 장에서 제일 먼저 눈에 들어오는 덩어리가 그 화면이 답하는 것인가**를 본다.
지금은 세션 없는 계정에서 그것이 빈 도넛이다.
