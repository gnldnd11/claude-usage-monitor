휠과 슬롯: 멈추는 곡선

검수용 비교판입니다. 제품 코드가 아니고, 글꼴은 측정값을 보존하려고 VS Code 의 기본 스택을 씁니다. 각 칸의 수치는 실제 엔진에서 뽑은 칸 각도·링 순서로 돌린 결과입니다.

1. 휠 — 지금 / 안 A / 안 B

세 개가 같은 칸에 섭니다. 다른 것은 곡선과 지속 시간뿐입니다. 「진행 중에 멈출 칸을 미리 칠한다」를 켜 보십시오. 켠 것이 지금 제품의 동작입니다.

바퀴

세로축은 각속도(deg/s), 가로축은 ms. 위 점선 1,100 deg/s 는 라벨이 토막으로 끊기기 시작하는 속도, 아래 점선 370 deg/s 는 가장 좁은 칸(24도) 하나가 65ms 이상에 지나가 라벨이 읽히기 시작하는 속도입니다.

2. 슬롯 — 지금 / 안

둘이 같은 자리에 섭니다. 왼쪽은 70ms 마다 5px 씩 떠는 지금 동작이고, 오른쪽은 릴 하나가 하나의 전환으로 링을 굴러 내려오는 안입니다. 왼쪽은 당첨 링이 릴마다 제 정지 시각에 켜집니다. 세 번째 릴이 아직 돌 때 답이 먼저 나옵니다.
